# 📜 "YOUR"Folio

A unique, tactile **paper and ink** aesthetic personal portfolio featuring interactive paper animations, 3D tilted index cards, a live Lanyard Discord widget, an interactive rubber ink stamp, and an ambient YouTube audio player.

[Live Demo](https://lyzyakakim.onrender.com) · [Report Bug](https://github.com/Lyzy01/Porfolio1v1/issues) · [Request Feature](https://github.com/Lyzy01/Porfolio1v1/issues)

---

## ✨ Features

* **Tactile Paper & Noir Modes:** Switch seamlessly between a warm cream notebook paper aesthetic and a dark noir ink wash mode with an animated background GIF blend.
* **Interactive Rubber Stamp:** Clickable stamp header that slams down with a web-audio thud sound effect and cycles through editorial stamps (`VERIFIED`, `APPROVED`, `ORIGINAL`, `OFFICIAL`).
* **Live Discord Integration:** Powered by [Lanyard](https://lanyard.rest/), displaying your live online status (Online, Idle, DND, Offline), profile badges, and current game/Spotify activity in real time.
* **Paper Physics & Animations:** Includes custom 3D card tilt effects on hover, smooth page-peel entry cover, floating paper scraps, and an ink-splat mouse cursor trail.
* **Ambient Audio Player:** Built-in mini YouTube background audio player with volume control and an animated equalizer bar.

## 🚀 Getting Started

To run or customize this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Lyzy01/Porfolio1v1.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Porfolio1v1
   ```
3. **Open `index.html`:**
   * Double-click `index.html` to open it in your browser, or open it using **VS Code Live Server** to ensure the live Lanyard API fetches correctly without CORS issues.

---

## ⚙️ Configuration

If you want to sync your own live Discord status, open `index.html` and update your 18-digit Discord User ID near the bottom script section:

```javascript
const DISCORD_USER_ID = "1366110873248071801";
```
